A program that writes exactly one emoji — a night under the Milky Way — to
`entry.txt` as its dream vacation. The judge picks the emoji that most makes
a stranger want to book the flight; this one is the postcard moment every
dream trip starts with: a dark sky full of stars, far from home.

Run it with `python3 main.py`; it writes the emoji to `out/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when the harness sets it).
